Cas détaillé: Se déplacer (1/4)

1. Le poisson détermine les cases vides autour de lui sur les axes verticaux et horizontaux
2. Le poisson choisit une direction aléatoire vers l'une des cases vides
3. Le poisson se déplace sur cette case

Cas détaillé: Se déplacer (2/4)

1. Le poisson détermine les cases vides autour de lui sur les axes verticaux et horizontaux
2. Le poisson ne trouve aucune case vide. Il ne bouge pas

Cas détaillé: Se déplacer (3/4)

1. Le requin détermine le contenu des cases autour de lui sur les axes verticaux et horizontaux
2. Le requin choisit une direction aléatoire vers une case contenant un poisson ou une case vide
3. Le requin se déplace sur cette case

Cas détaillé: Se déplacer (4/4)

1. Le requin détermine le contenu des cases autour de lui sur les axes verticaux et horizontaux
2. Le requin ne trouve que des cases contenant des requins. Il ne bouge pas


Cas détaillé: Se reproduire (1/2)

1. Le poisson se déplace
2. Le temps de reproduction du poisson atteint, le poisson laisse un nouveau poisson à son ancienne position
3. Le temps de reproduction est remis à 0

Cas détaillé: Se reproduire (2/2)

1. Le requin se déplace
2. Le temps de reproduction du requin atteint, le requin laisse un nouveau requin à son ancienne position
3. Le temps de reproduction est remis à 0


Cas détaillé: Se nourir (1/2)

1. Le requin se déplace sur une case voisine contenant un poisson
2. Le requin mange le poisson
3. Le requin récupère son enérgie initiale

Cas détaillé: Se nourir (2/2)

1. Le requin ne trouve aucune case contenant un poisson
2. L'enérgie du requin est décrémenté de 1


Cas détaillé: Mourir (1/2)

1. Le poisson se trouve sur une case voisine d'un requin
2. Le requin mange le poisson
3. Le poisson est retiré de la population et de la grille

Cas détaillé: Mourir (2/2)

1. Le requin ne trouve aucune case contenant un poisson
2. L'enérgie du requin atteint 0
3. Le requin meurt
3. Le requin est retiré de la population et de la grille
